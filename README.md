# Lopputyö projekti
Tässä työssä tuli kyllä paljon kaikkee uutta kun ei ole itsellä yhtään koodaus taustaa, tämän projektin ansiosta innostuin vähän näistä ympäristöistä ja antaa hyvää pohjaa sitkun alottaa koodaamaan. Useassa kohdassa tuli paljon uusia ongelmia mutta sain ratkaistua kaikki loppuenlopuksi joka opetti paljon.
Opin nyt hyvin käyttämään peruskomentoja sekä vähän harvinaisimpia komentoja

kaikki käyttämäni komennot oli lähes uusia minulle. Esimerkiski:
git init, clone, add, pull, commit, rebase, stash pop ja oikeastaan kaikki aineistoissakin listatut komennot mutta keskeisinä noi 1-13 kohdan komennot.

Käytin apunani aina ensimmäiseksi omaa päätäni ja koitin ratkaista ongelmat
Seuraavaksi koittettiin ratkaista kaverin kanssa ja jos ei vieläkään turvauduttiin koulun aineistoihin tai googleen.

Suurimpana ongelmanani oli turhien committien poisto jossa en onnistunut, ilman että hajopitaisin jotain. välillä commitit tuli useita minuutteja myöhässä jonka takialuulin että ne ei tule lainkaan niin tein sen uudestaan jasiksi mulla on joitain committeja kahteen kertaan. yritin korjata rebasen avulla mutta epäonnistuin.

kerta kaikkiian oli haastava mutta mielenkiintoinen projekti!
